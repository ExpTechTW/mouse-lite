# MouseLite

MouseLite 是一個 macOS 選單列清量化工具，讓你針對每一支滑鼠或觸控板調整捲動方向、捲動速度、指標靈敏度，以及中鍵和側鍵動作，而不影響其他指標裝置或系統全域設定。

## 功能

- 控制滑鼠按鍵功能
- 調整靈敏度
- 自然滑動控制
- 設定即時生效，並自動檢查、安裝新版本

## 系統需求

- macOS 13 Ventura 或更新版本
- 輔助使用（Accessibility）權限
- 輸入監控（Input Monitoring）權限

MouseLite 是純選單列應用程式，不會出現在 Dock。

## 安裝與使用

1. 將 `MouseLite.app` 拖曳到「應用程式」資料夾並開啟。
2. 第一次啟動時，依系統提示允許「輔助使用」與「輸入監控」權限。
3. 點選選單列的滑鼠圖示，選取裝置後調整快速設定，或選擇「進階設定…」。
4. 在「進階設定」中選取裝置，變更會立即套用，不需要按儲存。

若已授權但功能沒有開始運作，請結束並重新開啟 MouseLite，或確認它仍列在「系統設定 > 隱私權與安全性」的兩項權限清單中。

```
xattr -dr com.apple.quarantine /Applications/MouseLite.app
```
